# 강의 스크립트(전사) 스키마 · 정본

> 확정: 2026-07-10 · 기준 구현체 = `02-challenge/stella-reader-wt/public/stella/transcripts/dll-1.json`
> 관련 정본: [access-tiers.md](../access-tiers.md) · [PLAYER-DEFINITION.md](./PLAYER-DEFINITION.md)
> **이 문서가 계약이다.** 로더(`src/lib/stellaLectures.js` `loadTranscript()`)와 생성 스크립트는 이 표를 따른다.

## 왜 스키마를 고정하는가

전사는 4개의 기능이 아니라 **하나의 자산**이다. `[타임코드 + 언어태그]` 한 번의 투자에서 아래가 전부 파생된다.

| 용도 | 쓰는 필드 | 수혜자 |
|---|---|---|
| 자막 오버레이 | `start` `end` `text` | 청각장애 · 소리 못 켜는 환경 |
| 가라오케 하이라이트 | `start` (재생시각과 비교) | 전체 학습자 |
| 스크린리더 낭독 | `lang` (SR TTS 언어 전환) | 시각장애 |
| AI 요약 · RAG · 검색 | `text` `kind` | 텔라 · 콘텐츠 파이프 |

`lang`이 없으면 스크린리더가 영어 문장을 한국어로 읽어 뭉갠다. `kind`가 없으면 저작권 필터를 걸 축이 사라진다.
**둘 다 세그먼트 단위 필수다.**

## 파일 규약

```
무료 구간(OT · 1~5강)   public/stella/transcripts/{id}-{no}.json    ← 정적 서빙 허용
유료 구간(6강~)          Worker 게이트 뒤                             ← 🔴 public/ 절대 금지
```

- `{id}` = **`stellaBookFor(g).id`** (`dll` 키다리 · `oz` 오즈). ⚠️ 파일 안의 `g` 값이 아니다.
  `g`는 리더 **그룹 id**(`"157"` 키다리 · `"55"` 오즈)이고, 파일명 접두사는 그 그룹의 `id`로 매핑된다.
  매핑 단일 소스 = `src/lib/stellaLectures.js` `MAP`.
- `{no}` = 강의 번호(정수). ⚠️ **OT는 `dll-0.json`(`lecture: 0`)이다.**
  `StellaLectureSheet`가 OT를 `sel = 0`으로 다루고 로더가 `` `${id}-${sel}` `` 로 fetch하기 때문.
  `dll-ot.json` 으로 저장하면 앱이 영원히 404를 받는다(로더는 404를 조용히 삼킨다 → 증상 없이 대본만 사라짐).
- **전사의 접근 권한 = 해당 강의의 접근 권한.** 영상이 T2 전용이면 그 전사도 T2 전용이다.
- `public/`에 두고 링크를 안 거는 것은 보호가 아니다. URL만 알면 전 세계가 읽는다.
- 유료 구간 서빙 = Worker `literstella-audio-gate` 의 **`GET /transcript/kidari/{ot|NN}.json`**
  (오디오와 같은 규칙: `ot`·`01`~`05` 무통과 / `06`~`60` 은 HMAC 서명 토큰 `?t=`, 실패 시 403 `locked`).
  응답에 `x-robots-tag: noindex, nofollow`. 객체는 비공개 R2 `transcript/kidari/{ep}.json`.
  토큰 발급은 수강 인증(T2)이 붙는 곳의 몫 — 그전까지 6강+ 는 구조적으로 항상 403이다.

### ⚠️ 타임코드는 '어느 미디어'의 것인지 고정하라
전사의 `start/end`는 **원본 강의 미디어**의 타임라인이다. 데모용으로 잘라 둔 짧은 오디오
(`public/stella/audio/dll-01.mp3` = 283초)와 1강 전사(3,349초)는 **서로 다른 타임라인**이다.
둘을 `audioUrl`로 이어 붙이면 문장 클릭이 오디오 길이 밖으로 seek 한다 — 무동작 결함의 재발이다.
미디어를 붙일 때 `durationSec`와 실제 미디어 길이가 일치하는지 먼저 확인한다.

## 최상위 객체

| 필드 | 타입 | 필수 | 설명 |
|---|---|:--:|---|
| `g` | string | ✅ | 리더 **그룹 id** (`"157"` 키다리 · `"55"` 오즈). `stellaBookFor(g)`로 해석된다. |
| `lecture` | number \| `"ot"` | ✅ | 강의 번호. 파일명 뒷부분과 일치. |
| `durationSec` | number | ✅ | 미디어 총 길이(초). 모든 `end`의 상한. |
| `transcript` | Segment[] | ✅ | 아래 참조. 빈 배열 금지(전사가 없으면 파일을 만들지 않는다). |
| `note` | string |  | 출처·생성 메모. 예: 원본 강의 파일명, 생성 파이프라인. |

## Segment 객체

| 필드 | 타입 | 필수 | 설명 |
|---|---|:--:|---|
| `start` | number | ✅ | 시작 시각(초). `0` 이상. |
| `end` | number | ✅ | 종료 시각(초). `start`보다 크다. |
| `lang` | `"ko"` \| `"en"` | ✅ | 세그먼트의 **주** 언어. 혼용 문장은 다수 언어를 적는다. |
| `kind` | `"lecture"` \| `"quote"` | ✅ | `lecture`=강사 발화 / `quote`=원서 본문 인용(낭독). |
| `text` | string | ✅ | 발화 텍스트. 앞뒤 공백 제거. |

### 불변식 (검증기가 강제)

1. `start` 오름차순 정렬, 세그먼트끼리 **겹치지 않는다**.
2. 모든 세그먼트에서 `start < end ≤ durationSec`.
3. `lang` · `kind`는 위 열거값만. `null`·누락 금지.
4. `g` · `lecture`가 파일명과 일치.

기준 파일 `dll-1.json` 실측: 세그먼트 30개 · `durationSec` 204.6 · `lang` ko 23 / en 7 · `kind` lecture 23 / quote 7.

## 🔴 `kind`가 저작권 필터 축이다

`kind: "quote"` = 원서 본문을 소리 내어 읽은 구간. 이 태그 하나로 작품별 정책이 갈린다.

| 작품 | 저작권 | `quote` 세그먼트 처리 |
|---|---|---|
| 키다리 아저씨 (1912) | 퍼블릭 도메인 | 그대로 노출 가능 |
| 오즈의 마법사 (1900) | 퍼블릭 도메인 | 그대로 노출 가능 |
| **해리포터 (1997)** | **보호 중** | **제품 표면에서 제거.** 본문 0% · 강의 100% |

해리포터 전사는 강독 특성상 영어 본문 조각이 섞인다. 뉴스레터·리더·텔라에 실을 때
`kind === 'quote'` 세그먼트를 **필터링해 걸러낸다.** 영어 인용이 필요하면 Day당 1문장 수준 + 출처 표기.

## 생성 파이프라인

```
영상/오디오 → ffmpeg 16kHz mono 48k mp3 → Groq whisper-large-v3 (verbose_json)
           → segments[{start,end,text}]  ← 타임코드는 여기서 나온다
           → lang · kind 부여            ← 한글 자모 유무 + 낭독 구간 판정
           → {g}-{no}.json
```

- 전사 원본(강사 IP)은 `E:\LiterStella_전사\` 로컬 보관. **git 금지 · 업로드 금지.**
- **`lang` 규칙: 한글이 한 글자라도 있으면 `ko`.** 강사가 영어 어구를 섞어 설명하는 문장은 '한국어 문장'이다.
  이걸 `en`으로 태깅하면 스크린리더가 한국어를 영어 음소로 읽어 내용이 통째로 소실된다.
  (손보정 30세그를 정답지로 대조해 확정. '한글 비율 30% 초과' 같은 임계값은 `"그냥 awful day 해도 …"` 류를
  놓친다 — 실제로 놓쳤다.)
- **`kind` 규칙은 초안이다.** 현재 = `en` && 어절 5개 이상 → `quote`.
  🔴 **해리포터처럼 보호 중인 작품엔 이 어절수 휴리스틱을 쓰지 말 것.** 저작권 필터 축이므로
  원문 텍스트와 대조해 판정해야 한다. 키다리·오즈는 퍼블릭 도메인이라 오태깅이 법적 위험을 만들지 않는다.
- 자동 판정은 초안이다. 무료 공개 구간(OT·1~5강)은 사람이 한 번 훑는다.
- 생성기 = `E:\LiterStella_전사\dll_build_transcripts.py`
  (강의↔소스 매핑은 **페이지 범위** 기준 · 재전사본 `_re`/`noise_cut`/`오디오수정` 우선 ·
  6강 이상을 `public/` 경로에 쓰려 하면 **즉시 중단**하는 하드가드 + 사후 유출 검사 내장).

## 검증

`scripts/validate-transcripts.mjs` 로 불변식 4종을 검사한다. 새 전사를 `public/stella/transcripts/`에
추가하기 전에 반드시 통과시킨다. 실패하면 자막이 어긋나거나 스크린리더가 언어를 잘못 읽는다.
