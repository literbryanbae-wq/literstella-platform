# 뉴스레터 발행 전략 — 정본 (운영자 확정 2026-07-13)

> 이 문서 = 발행 전략의 정본. 3분 오디오 시그니처 + 매일 뉴스레터 분리 기획 + 제작 모델.
> 근거·대안은 워크플로 종합안(세션 대화). 이름·카피·거처는 아래 '확정' 표시 외엔 제안.

## 0. 한 줄 요약

**두 개의 매일, 두 개의 브랜드.** 같은 씨앗('오늘의 한 문장')을 두 번 우려먹지 않는다.
- **「스텔라의 클래식 영어 한 문장」**(3분 오디오·시그니처) = *느끼게 하는* 감성 채널(귀·심화·문학).
- **매일 뉴스레터**(가벼움·새 기획) = *써먹게 하는* 실용 채널(눈·짧게·제품 CTA).
- **철칙: '한 문장의 해설'은 오디오(+그 페이지)에만 산다. 뉴스레터는 그 문장을 다시 풀지 않고 '들어보기 →' 링크로만 인용한다.** (단일 출처 + 다중 유통)

## 1. 병목 재정의 (운영자 통찰)

스토리 극장·강독·팟캐스트 = **상록(evergreen) 카탈로그**. 클래식 원서라 한 번 제작 후 오류만 수정하고 영구 재사용 → '매일 짜내는 병목'이 아니라 '한 번 쌓는 서재'. **매일 발행 의무에서 완전 제외.** 한 원서를 세 깊이로: 스토리 극장(요약·무료) → 3분 한 문장(무료) → 강독(정독·유료) = 경쟁 아닌 **사다리**(무료→유료 예열).

## 2. 「스텔라의 클래식 영어 한 문장」 — 시그니처 (확정)

- **브랜드명(확정): 「스텔라의 클래식 영어 한 문장」** — 사람(스텔라=대체불가·유료 강독 강사 본인 목소리)+실체를 정직하게. 기존 뉴스레터 워드마크 "오늘을 여는 클래식 영어 한 문장"의 계승.
  - 🔴 **함의(중요): 이 워드마크가 이제 '오디오 시그니처'로 이동한다** → 기존에 이 이름을 쓰던 매일 이메일 뉴스레터는 **자기 이름을 새로 가져야** 겹침이 안 생긴다(§3 참조, 이름 후속 결정).
- **거처(확정): 전용 아카이브 페이지 먼저.** 사이트 내 상록 서재(기존 전사 자막 4뷰 자산 재사용) + SEO 유입 + 강독 전환 착지점. 팟캐스트 외부 배급(애플/스포티파이)은 2단계.
- **발행 빈도(확정): 주 3~4회로 시작.** 반응 보고 매일로 상향.
- **고정 포맷(한 번 정하면 재사용):**
  - 3분±20초. 3층 오디오 = 인트로 시그니처 음악(~14s) → 스텔라 육성(+베드 더킹) → 아웃트로 여운(~55s).
  - 오프닝 의식(고정): 스텔라 1인칭 인사 → 오늘의 원문 한 문장 낭독 → 우리말 번역 한 줄.
  - 본문 5문단: ①어느 원서·장면 ②문장이 품은 감정·배경 ③영어 표현의 결·리듬 하나 ④내 삶·영어로의 연결 ⑤다시 그 문장으로 여운.
  - 클로징 의식(고정): 첫 문장 수미상관 재낭독 → 동일 사인오프 한마디 + 문장번호(#Day 037).
  - 시각 1장: 세리프 '문장 카드'(원문+번역+원서 톤+문장번호) — 공유·팟캐스트 커버·개인 서재 적립 카드 공용.

## 3. 매일 뉴스레터 새 기획 (가볍게)

한 통 = **삽화 1장 + 짧은 텍스트 1코너 + CTA 1개.** 소재 고갈 방지 = **요일 로테이션**(오디오의 '한 문장 심화'와 다른 씨앗):

| 요일 | 코너 | CTA |
|---|---|---|
| 월 | 원서 소식·화제 큐레이션 | 진단·리더 |
| 화 | 오늘의 표현(그날 써먹는 실용 단어/표현 1개, ≠문학 심화) | 리더·단어장 |
| 수 | 독자 이야기(인증·완독 후기·독자가 고른 문장) | 챌린지 |
| 목 | 큐레이션('이번 주 이 책', 레벨/무드별) | 진단·다이어리 |
| 금 | 스텔라 비하인드 / 강독·완독클럽 소식 | 강독·클럽 |
| (주말) | 퀴즈·짧은 낭독 챌린지·밈 | 가볍게 |

- **매 통 하단 고정 앵커 위젯:** 🎧 오늘의 3분 — 《책 제목》의 한 문장 "…" 들어보기 → (티저+링크만, **해설 본문 없음**, 그날 실제 원서·문장 노출로 배너 블라인드 방지).
- 🔴 **후속 결정: 매일 뉴스레터의 새 이름/아이덴티티** — '클래식 영어 한 문장'을 오디오에 넘겼으니 매일 이메일은 새 이름 필요(예: 리터스텔라 데일리·오늘의 원서 등, 제안·운영자 확정).

## 4. 분리의 축 (왜 안 겹치나)

| 축 | 3분 오디오 | 매일 뉴스레터 |
|---|---|---|
| 감각 | 귀(듣는다) | 눈(읽는다) |
| 목적 | 느끼게(감상·예열) | 써먹게(정보·행동) |
| 채널 | 전용 페이지(→팟캐스트) | 이메일 |
| 깊이·톤 | 하나를 깊게·문학·느림 | 여럿을 얕고 넓게·실용·빠름 |

## 5. 제작 모델 — 실 육성 8개 + 클론 (확정)

- **포맷 표준화 → 배치 생산**(미리 만들어 스케줄로 흘림 = 병목 없음).
- **실 육성 8개 = 히어로 티어**: 키다리4·앤2·오만1·작은아씨들1. 해당 원서에 '⭐ 오리지널 보이스' 프리미엄 회차로 대표 진입점 고정.
- **나머지 = 스텔라 PVC 클론**(`c84b1444bf5140a39c588dd0b543802c`, [[tts-voice-platform]]) 동일 포맷.
- **표기(확정): 실육성 8개에만 '오리지널 보이스' 태그.** 클론은 그냥 '스텔라 목소리'로 통칭(회차별 라벨링으로 김빼지 않음) + **서비스 소개/약관에 "일부 회차는 스텔라의 AI 음성으로 제작" 1회 전역 고지**(법·윤리). 방향 = 클론을 낮추는 게 아니라 실육성을 올리는 희소성 서사.
- **3층 오디오 파이프라인**: [[story-theater-pipeline]]의 story_audio_v2 계열 재사용(단, 뉴스레터 에세이는 `wrap_newsletter.py` 정본 — 문서-코드 불일치 주의: AUDIO_ASSETS는 -18dB 더킹 설명이나 현행 뉴스레터 조립은 클린보이스+인트로/아웃트로).

## 6. 실행 로드맵

1. **포맷·사인오프 확정** — 오프닝/클로징 문구 확정. 🔴선행: **스텔라 본인 목소리 라이선스 서면 확인**(클론 사용의 법적 전제).
2. **파일럿 배치 생산** — 실육성 8개 앵커 정리 + 클론 5~10회차 미리 제작(파이프라인 표준화 검증).
3. **전용 아카이브 페이지 셋업** — 사이트 내, 전사 자막 재사용. 문장→원서→리더→강독 착지.
4. **매일 뉴스레터 새 포맷 전환** — 요일 로테이션 + 하단 앵커 위젯. 매일 뉴스레터 새 이름 확정.
5. **주 3~4회 발행·측정** — 오디오→원서 페이지→리더→강독 착지율 측정 후 CTA·빈도 조정.

## 7. 위험·주의

- **클론 라이선스·고지**: 서면 라이선스가 모든 것에 선행. 전역 고지 1회 필수.
- **이메일 피로**: 주 3~4회로 시작, '가벼움' 사수.
- **소재 고갈**: 요일 로테이션 + 상록 아카이브 재소개. 1인 지속가능성 실측.
- **유료 잠식 방지**: 3분=한 문장 맛보기 감성 / 강독=풀코스 정독. 깊이 분리 = 잠식 아닌 예열.
- **브랜드 혼선**: 오디오는 독립 브랜드로 인식되게(뉴스레터 한 코너 아님). 매일 뉴스레터 이름 분리 필수.
