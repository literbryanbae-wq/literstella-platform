## 해리포터 (HP) — 뉴스레터 무료 / 그 외 완독 클럽 전용

| 콘텐츠 | T0 | T1 | TC 완독 클럽 |
|---|:--:|:--:|:--:|
| 뉴스레터 (content-pack) | ✅ | ✅ | ✅ |
| 이야기극장 | 🚫 | 🚫 | ✅ |
| 클럽 전용 페이지 일체 | 🚫 | 🚫 | ✅ |

### 🔴 웹 노출 절대 금지 — 4겹 (운영자 지시 2026-07-10)
1. **`public/` 금지.** Pages의 `public/` 아래 파일은 URL만 알면 전 세계가 읽는다. HP 클럽 콘텐츠는 **Worker + 비공개 R2**에만 둔다. 비밀 URL은 보호가 아니다.
2. **회원 판정.** 링크 소지가 아니라 클럽 명단 매칭으로 통과시킨다(비밀 링크는 한 번 새면 회수 불가).
3. **색인 차단.** `X-Robots-Tag: noindex, nofollow` 응답 헤더 + sitemap 제외 + 랜딩 SSG 카탈로그 제외 + 앱 내 링크 노출 금지.
4. **robots.txt에 경로를 쓰지 말 것.** `Disallow: /club/hp`는 경로를 광고하는 셈이다.

### 🔴 저작권 — HP는 키다리와 다르다
키다리(1912)=퍼블릭 도메인, **HP(1997)=저작권 보호 중.**
- **본문 0% · 강의 100%.** 원문 텍스트를 제품에 싣지 않는다.
- 이야기극장 낭독 = **우리말 재서술**(원문 낭독 아님). 영어 인용은 Day당 1문장 수준, 출처 표기.
- **HP 상표를 유료 상품명으로 쓰지 않는다.** 무료 뉴스레터·커뮤니티 명칭은 현행 유지.

## 수강 인증 (T2 승급) — 2단 하이브리드

1. **자동 매칭** — 운영자가 제공한 수강생 명단을 `class_enrollments(email, book_code, granted_at)`에 적재.
   로그인 이메일이 명단에 있으면 사용자 조작 없이 해금.
2. **인증 코드** — 결제 이메일 ≠ 로그인 이메일인 경우.
   6강 해금 모달에서 코드 1회 입력 → 계정에 영구 귀속(`redeemed_by` 기록, 재사용 불가).
3. **미인증** → 강독 클래스 구매 CTA.

### 🔴 보안 요건 (비타협)
- 수강생 명단 = **PII**. anon 키로 절대 SELECT 불가.
- 접근은 **SECURITY DEFINER RPC** `check_my_class_access()` 만 허용 (본인 행만 반환).
- 명단 테이블 자체 REVOKE + allowlist GRANT (교훈: 컬럼 REVOKE는 테이블 GRANT 있으면 무효).

## 저작권 보호 — 법적 층 ≠ 기술적 층

**동의 체크박스는 유출을 막지 못한다. 책임 근거를 만들 뿐이다.**
재생되는 오디오는 저장된다 — 예외 없음. 아래 3층을 함께 쌓는다.

| 층 | 조치 | 막는 것 |
|---|---|---|
| ① 원본 은닉 | R2 객체 끝까지 비공개, Worker만 통과 | 공유 가능한 원본 URL이 애초에 없음 |
| ② 서명 URL | 유료 구간 = 10분 만료 + 계정 id 바인딩 | 링크 복사·재배포 (유출 시 추적 가능) |
| ③ 다운로드 억제 | 다운로드 버튼 미제공 + `controlsList="nodownload"` | 일반 사용자의 손쉬운 저장 |
| ④ 동의 기록 | 유료 구간 첫 재생 전 1회: `동의시각·계정·IP·강의ID` | (법적) 유출 시 책임 소재 |

- **무료 구간(1~5강)엔 ④를 붙이지 않는다** — 마찰만 늘고 지킬 게 없다.
- ③은 개발자 도구 사용자를 막지 못한다. 그 사용자에겐 ②의 로그가 남는다.

## Worker 게이트 계약 (`literstella-audio-gate`)

```
GET /lecture/kidari/{ot|01..60}.mp3
  01~05, ot  → 무조건 스트리밍 (Range 지원)
  06~60      → 서명 토큰(?t=) 필수. 검증 실패 → 403 {error:'locked'}
               토큰 = HMAC(uid + ep + exp), exp ≤ 10분
GET /transcript/kidari/{ot|01..60}.json     ← 강의 스크립트(전사). 오디오와 동일 규칙.
  01~05, ot  → 그대로 서빙 (앱은 무료분을 public/stella/transcripts/dll-{0..5}.json 로 정적 서빙)
  06~60      → 서명 토큰 필수. 실패 → 403 {error:'locked'}
               응답 헤더 x-robots-tag: noindex, nofollow · 객체 = transcript/kidari/{ep}.json (비공개 R2)
GET /story/... → 로그인 세션 확인 (Day 6+)
```
- **전사 = 강사 IP.** 6~60강 전사는 `public/` 에 두지 않는다. 생성물은 `E:\LiterStella_전사\gated\transcripts\`
  (저장소 밖) → R2 업로드 후 위 라우트로만 서빙. 생성기에 public 유출 하드가드가 걸려 있다.
- 토큰 발급(minting)은 수강 인증(`class_enrollments`)이 붙는 곳의 몫. 그전까지 6강+ 는 항상 403이다.
- 원본 R2 버킷 `literstella-audio` = **영구 비공개**. 공개 전환 금지.
- 무료 스토리·뉴스레터 자산만 공개 버킷 `literstella-story`.
