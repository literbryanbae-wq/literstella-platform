# 리딩 스튜디오 (Reading Studio) — 설계 스펙

> 작성: 2026-06-26 · 대상: 다이어리/스튜디오 구현 세션 · 상태: 설계 확정안(운영자 방향 반영)
> 목적: 흩어진 독서 도구(꾸미기·필사노트·타이머·카드·설정)를 **하나의 확장형 허브**로 통합 = 차별화·장기 리텐션·락인 장치.

---

## 0. 한 줄 정의

**리딩 스튜디오 = "나의 독서 작업실".** 다이어리 모드(비경쟁 성소) 안에서 모든 창작·도구·설정을 한 곳에 모은 허브. 도구를 계속 추가·업그레이드할 수 있는 **플랫폼 구조**(기성 앱들과 차별화 = 우리만의 통합 독서 스튜디오).

핵심 원칙
- **모바일(터치) 1순위 → PC → 패드** 순 최적화.
- **비경쟁 불변**([[reading-sanctuary]]): 스트릭·랭킹·포인트 숫자 노출 금지. 도구·창작·기록만.
- **확장형**: 새 도구(단어장·커뮤니티 등)를 동일 타일 규격으로 무한 추가.
- **테마 상속**: 사용자 다이어리 미감(`--d-accent` 등)을 스튜디오 전체가 상속.

## 1. 네이밍

| 레벨 | 명칭 |
|---|---|
| 허브(통칭) | **리딩 스튜디오 · Reading Studio** |
| 진입 버튼 | `🎨 스튜디오` (헤더/다이어리 모드) |

도구 명명 규칙: **명사 단문**(동사형 금지) — "꾸미기/필사노트/독서 타이머/카드 만들기/설정".

---

## 2. 구성 도구 (현재 5개 · 확장 가능)

| 도구 | 통일 명칭 | 아이콘(lucide) | 기존 자산(재사용) | 설명(부제) |
|---|---|---|---|---|
| 꾸미기 | **꾸미기** | `Palette` | ReadingDiarySection 테마 프리셋 · `onOpenDecorate` | 테마·미감 바꾸기 |
| 필사노트 | **필사노트** | `NotebookPen` | SanctuaryShelf · `open-sentence-notebook` 이벤트 | 모은 문장 손글씨·인쇄 소장 |
| 독서 타이머 | **독서 타이머** | `Timer` | `PomodoroTimer` (시간 칩 런처) | 책 속으로 몰입 타이머 |
| 카드 만들기 | **카드 만들기** | `Image` | `DiaryCardTeaser`·`PhotoShareCard`·`DiaryShareCard` | 다꾸·사진 스탬프 공유 카드 |
| 설정 | **설정** | `Settings` | reading-tools-settings-epic | 타이머·필사노트·테마 세부 설정 |

> 🚫 이모지 아이콘 직접 렌더 금지(렌더 깨짐) — 전부 lucide. 타일 명칭/순서/아이콘은 이 표가 단일 소스.

미리보기 통합: 기존 `DiaryCardTeaser`(3종 카드 미리보기)는 **"카드 만들기" 타일의 첫 화면**으로 흡수. 별도 떠다니는 미리보기 제거 → 스튜디오 안에서 일원화.

---

## 3. 진입 동선

- **다이어리 모드 전용**(챌린지 모드엔 노출 안 함 — 성소 도구).
- 진입점 **2곳(동일 허브 오픈)**:
  1. 헤더의 분산된 `꾸미기`·`필사노트` 버튼 → **단일 `🎨 스튜디오` 버튼**으로 통합.
  2. 다이어리 모드 상단 **"리딩 스튜디오" 접이식 패널**(기본 접힘, 펼치면 타일 그리드).
- 허브에서 타일 탭 → 해당 도구 열림(모달/시트 또는 인라인). 도구 명칭·아이콘은 §2 표 그대로.

---

## 4. 레이아웃 / 반응형 (퍼펙트 책임)

타일 그리드는 `repeat(auto-fit, minmax(…))`로 자동 리플로우.

| 해상도 | 폼 | 그리드 |
|---|---|---|
| **모바일 ≤640** (1순위) | 하단 **바텀시트**(또는 인라인 접이식) | **2열** 타일 `minmax(140px,1fr)` |
| **PC ≥1024** (2순위) | 다이어리 상단 가로 **독(dock)** 또는 그리드 | **4–5열** 한 줄 |
| **패드 641–1023** (3순위) | 인라인 패널 | **3열** |

공통 규격
- 터치 타깃 **≥48px**(타일 최소 높이 88px 권장), 인접 간격 ≥8px.
- 높이 단위 **100dvh**(+`min-height:100dvh`), iOS **safe-area-inset** 적용.
- 입력 폰트 ≥16px(iOS 줌 방지).
- **뒤로가기 연동**: 허브·각 도구는 `useModal`/`useBackClose`로 폰 뒤로가기 시 사이트 이탈 없이 닫힘(LIFO).
- 다크/라이트 양 테마 대비 확인 · `--d-accent`/`--ls-*` 토큰만(하드코딩 금지).

### 타일 해부(공통 규격)
```
[아이콘 타일 40×40, --d-accent 틴트] [명칭(15/900)] [부제(12.5, muted)]  → 탭 시 도구 오픈
```
- 카드 셸: radius 16, 1px 토큰 보더, `--d-card` 배경, hover/press 시 살짝 떠오름(translateY -2px).
- 한 번에 하나의 도구만 활성(허브는 그리드, 도구는 시트/모달로 위에 오픈).

---

## 5. 인터랙션 표준

- 타일 탭 → 도구 오픈(`useModal`: ESC·배경·뒤로가기·스크롤락·포커스 자동).
- 백그라운드 지속 도구(독서 타이머)는 **'창 내리기(최소화)'** 제공 → 작은 플로팅 필로 접되 카운트 유지(닫기와 별개). (DoD 오버레이 규칙)
- 도구 간 이동: 허브로 돌아오기(뒤로가기/X) → 다른 타일 선택.
- 모든 풀스크린 오버레이: 배경 클릭=닫힘 기본.

---

## 6. 확장 규칙 (도구 추가 시)

새 도구 = §2 표에 1행 추가 + 타일 1개 + 도구 컴포넌트. 그리드는 자동 리플로우라 레이아웃 변경 불필요.
- 예정: **단어장**(`BookA`/`Languages`), **커뮤니티장**(`Users`) — 동일 타일 규격으로 추가.
- 새 도구도 비경쟁 원칙·테마 상속·뒤로가기 연동 필수.
