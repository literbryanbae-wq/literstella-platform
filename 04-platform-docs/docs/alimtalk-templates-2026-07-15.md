# 카카오 알림톡 템플릿 팩 (심사 제출용) — 2026-07-15

> 알림톡 = **정보성 메시지 전용**(거래·서비스 이용 알림). 광고성 문구(무료·할인·쿠폰·이벤트·가입 유도)가 한 줄이라도 있으면 반려됩니다.
> 마케팅 블라스트(기존 3천명 오픈 안내 등)는 알림톡 **불가** → 친구톡(채널 친구만, (광고) 표기, 야간 금지) 또는 이메일(스티비)로.
> 발송 구현은 8월 카드결제 라이브와 동반(payment-portone-sequencing 계획), 이 문서는 사전 심사용 템플릿 정본.

## 공통 규칙 (심사 통과 원칙)

- 본문에 **발송 사유 명시** ("~신청하신 분께 발송되는 안내 메시지입니다") — 정보성 근거를 문면에 드러냄
- 변수는 `#{변수명}`, 본문 최대 1,000자, 변수로 문장 시작 금지(이름 앞 인사 배치)
- 금지: 무료/할인/쿠폰/이벤트/혜택/지금 신청 등 판촉 표현, 과도한 이모지·특수문자
- 버튼: 웹링크(WL), 모바일/PC URL 동일. 전 버튼 `utm_source=alimtalk&utm_medium=message` 부착(Phase 0 측정 배선이 자동 귀속)
- 프로젝트 금지어 준수: "완주"→성공/완독, "여정"·"도반"·"기수" 사용 안 함

## 제출 절차 (운영자)

1. **사전 준비**: 카카오 비즈니스 채널 인증(채널 `_xkxdZxeb` 비즈니스 전환) · 발송대행사 선택(솔라피/NHN Cloud/알리고 등 — 건당 7~9원대, 결정 필요) · 발신프로필 키 발급
2. 대행사 콘솔 → 알림톡 템플릿 등록 → 위 9종 각각 입력(유형=기본형, 버튼=웹링크, 변수 그대로)
3. **검수 리드타임 1~2주** 여유 두기(반려 시 수정 재검수). 8월 결제 라이브 역산으로 7월 중 제출 권장
4. 승인 후: 발송 배선은 Claude가 `05-secure-api` 워커에서 대행사 REST API 호출로 구현(라이프사이클 이메일 트리거와 페어, 멱등키 재사용)
